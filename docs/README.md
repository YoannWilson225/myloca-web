## 💡 Conventions

### Symboles utilisés

- ✅ : Fonctionnalité implémentée
- 🚀 : Action à effectuer
- 📝 : Note importante
- ⚠️ : Avertissement
- 💡 : Astuce
- 🔧 : Configuration
- 🎨 : Design/Style
- 📊 : Statistiques/Données

### Code Samples

Les exemples de code suivent cette convention :

```typescript
// ✅ Bon - À faire
const { theme } = useTheme();

// ❌ Mauvais - À éviter
const color = '#FFFFFF';
```
